🌐 My Portfolio Website
📖 About This Project

This is my personal portfolio website. I created it to show what I have been learning while studying web development.

The website includes information about me, the skills I am learning, and some of the projects I have worked on. It also shows my GitHub repositories so visitors can see the projects and code that I have published.

This project helped me practice using HTML, CSS, and JavaScript together to build a complete webpage.

✨ Features

👤 About section with information about me

🧠 Skills section listing technologies I use

📂 Projects section showing my GitHub repositories

💬 Message section where visitors can leave a message

📱 Responsive design that adjusts to smaller screens

🛠 Technologies Used

HTML – used to build the structure of the website

CSS – used to style the page and control the layout

JavaScript – used to add interactive features

GitHub API – used to fetch and display my repositories

⚙️ How It Works

The projects section uses JavaScript to request data from the GitHub API. The website fetches my public repositories and adds them to the page automatically.

This means when I add new repositories to GitHub, they can also appear on my portfolio.

💬 Message Section

The website also includes a message section where visitors can leave a message. This allows someone to write a short note directly on the portfolio page.

✏️ How To Use It

Enter your name in the name field

Enter your email address

Type your message in the message box

Click the Submit button

After the form is submitted, the message will appear on the page in the message list.

🧠 What I Practiced

While building this feature I practiced:

Creating HTML forms

Using JavaScript event listeners

Getting values from form inputs

Creating elements with JavaScript

Updating the page using the DOM

⚠️ Note

This message section only displays messages on the page. The messages are not stored in a database and will disappear if the page is refreshed.
